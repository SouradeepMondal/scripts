# Scripts

This repository contains some custom scripts that can be used in a Unix System
1. [hdiskTempInfo](./hdiskTempInfo.sh) -> check the temperature of an HDD.
2. [installerCheck](./installerCheck.sh) -> checks whether a hardcoded list of tools is installed or not. If installed also print the version.
3. [pre commit](./pre-commit) -> modified default git pre-commit script to run `Gitleaks` on staged changes.
